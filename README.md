# My Hyprland Dotfiles

My personal **Hyprland desktop configuration for Fedora Linux**, customized around my own workflow, preferences, and daily use.

## What This Is

This repository contains my active `~/.config/hypr` configuration, including:

* Window rules
* Keybindings
* Animations
* Hyprlock
* Hypridle
* Theming and colors
* Custom scripts
* Wallpaper management

This configuration represents how I currently use and customize Hyprland on Fedora Linux.

## My Setup

I initially experimented with a pre-built Hyprland setup, but later removed it and customized my environment to better fit my own workflow.

The current configuration is **my own customized setup** rather than a direct copy of a pre-built Hyprland framework.

## Structure

```text
hypr/
├── configs/                  # Modular configuration files
│   ├── keybinds.conf
│   ├── animations.conf
│   ├── windowrules.conf
│   └── ...
│
├── scripts/                  # Custom scripts
│   ├── lockscreen
│   ├── wallpaper
│   └── ...
│
├── hyprland.conf             # Main Hyprland configuration
├── hyprlock.conf             # Lock screen configuration
├── hypridle.conf             # Idle and lock behavior
└── matugen-colors.conf       # Color scheme
```
