# My Hyprland Dotfiles

My personal Hyprland desktop configuration for Fedora Linux, built on top of 
[JaKooLit's Fedora-Hyprland installer](https://github.com/JaKooLit/Fedora-Hyprland) 
as a base, with my own customizations layered on top.

## What this is
This repo contains my active `~/.config/hypr` configuration — window rules, 
keybindings, animations, lock screen, and theming — as I use it day to day.

## Base
Initial setup and installer scripts credit to JaKooLit's Fedora-Hyprland project. 
This repo reflects my personal edits and configuration choices on top of that base, 
not a standalone framework.

## Structure
hypr/
├── configs/          Modular config files (keybinds, animations, window rules, etc.)
├── scripts/          Custom scripts (lock screen, wallpaper switching)
├── hyprland.conf     Main config entrypoint
├── hyprlock.conf     Lock screen configuration
├── hypridle.conf     Idle/lock behavior
└── matugen-colors.conf   Color scheme

## Notes
Shared here as a reference for my own setup and to show hands-on experience 
configuring and customizing a Linux desktop environment.
